# BMEN600BTTB
BMEN600 final project repository (Group 4)
1. We want to investigate 3 different CT imaging modalities and compare resolution and image quality based on identifying different structural abnormalities in the bone. We will do this using 8 cadaveric wrists and imaging them on micro CT of each carpal bone, and HR-pQCT and Photon Counting CT data of the full fore arm bone. Our biggest uncertainty is the previous conditions of the patients given they are cadaveric specimens.
2. We want to investigate the radiomic features in liposarcomas using CT/MR with specific mutations/expression clusters. Our biggest uncertainty is the high heterogeneity when comparing samples to each other. 
revise - the overall project works, but we need to change - Sarcoma radiogenomic datasets are extremely limited (5 verified matched datasets). Non-sarcoma cancer types have much more accessible matched radiogenomic datasets. Training a model on non-sarcoma datatypes may introduce unknown variables relative to sarcoma-specific gene over or under-expression, if that model were to be applied to sarcoma specific datasets.
